# 🎸 Sacrilegium Guitar Project (TT7) - Open-Source Headless Guitar Design

Welcome to the **Sacrilegium Guitar Project (TT7)**! 

This is an open-source, community-driven electric guitar body design[cite: 1, 2]. The goal of this project is to blend an aggressive, ergonomic double-cut body silhouette with the lightweight balance of a headless guitar—completely eliminating the classic *neck dive*.

## 🛠️ CNC & Manufacturing Specs (Template / Dima)

The repository includes ready-to-use vector templates designed for CNC milling (e.g., via Inventables Easel or software like Fusion 360 / VCarve)[cite: 1, 2].

| Parameter | Specification |
| :--- | :--- |
| **Material / Stock Size** | `360 mm x 430 mm x 6 mm` (MDF / Plywood Template)[cite: 2] |
| **Bit / Endmill Diameter** | `1/4 in` (6.35 mm)[cite: 2] |
| **Project File Type** | SVG Vettoriale, Easel Archive, `.txt` settings[cite: 1] |
| **Body Type** | Solidbody Headless (Double Cutaway) |
